## Task 2 (nested — ActivationRange DAB-lite)

In `io/papermc/paper/entity/activation/ActivationRange.java`:

- Static holder (lazy, built once):

```java
    // SourbyCraft S6 - dab.entity-overrides: per-type [maxTickFreq, activationDistMod] (DAB-lite)
    private static volatile java.util.Map<net.minecraft.world.entity.EntityType<?>, int[]> sourbyDabOverrides;

    private static java.util.Map<net.minecraft.world.entity.EntityType<?>, int[]> dabOverrides() {
        java.util.Map<net.minecraft.world.entity.EntityType<?>, int[]> map = sourbyDabOverrides;
        if (map == null) {
            java.util.HashMap<net.minecraft.world.entity.EntityType<?>, int[]> built = new java.util.HashMap<>();
            for (java.util.Map.Entry<String, int[]> e : dev.iyanz.sourbycraft.SourbyCraftConfig.dabEntityOverrides.entrySet()) {
                java.util.Optional<net.minecraft.world.entity.EntityType<?>> type =
                    net.minecraft.world.entity.EntityType.byString(e.getKey());
                if (type.isPresent()) built.put(type.get(), e.getValue());
                else dev.iyanz.sourbycraft.util.SourbyLogger.warn("dab.entity-overrides: unknown entity type '" + e.getKey() + "'");
            }
            sourbyDabOverrides = map = java.util.Map.copyOf(built);
        }
        return map;
    }
```

- Activation-distance mod: at the site where the entity's activation range is
  resolved per type (the switch/lookup feeding the range comparison), subtract
  `override[1]` with floor 4 when an override exists.
- Inactive cadence: in the S2 gate region (inactive wakeup), when an override
  exists use `max(20, override[0])` as the minimum ticks between wakeups for
  that type (takes precedence over the global tick-rate stretch).
- Empty map fast path: `dabOverrides().isEmpty()` short-circuit before any
  per-entity lookup.
