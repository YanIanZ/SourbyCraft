> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Tech Stack:** Java 21 (compile), Java 21-25 (runtime), Gradle 9.4, Paperweight 2.0, fastutil, jdk.incubator.vector

### Task 1: Bundle paperclip.conf

**Files:**
- Create: `paperclip.conf`

- [ ] **Step 1: Create paperclip.conf**

```properties
# SourbyCraft JVM configuration
# Applied by paperclip at server startup

# ZGC with generational mode (Java 21+)
-XX:+UseZGC
-XX:+ZGenerational

# Class Data Sharing for faster startup
-XX:+AutoCreateSharedArchive
-XX:SharedArchiveFile=sourbycraft-cds.jsa

# Container-aware memory
-XX:+UseContainerSupport

# Module opens for Java 22+ compat
--add-opens=java.base/java.lang=ALL-UNNAMED
--add-opens=java.base/java.util=ALL-UNNAMED
--add-opens=java.base/java.io=ALL-UNNAMED
--add-opens=java.base/java.lang.invoke=ALL-UNNAMED
--add-opens=java.base/java.lang.reflect=ALL-UNNAMED
--add-opens=jdk.incubator.vector/jdk.incubator.vector=ALL-UNNAMED

# Soft refs clear on OOM, not GC pressure
-XX:SoftRefLRUPolicyMSPerMB=0
```

- [ ] **Step 2: Verify file is valid**

```bash
java -XX:+PrintFlagsFinal --add-opens=java.base/java.lang=ALL-UNNAMED -version 2>&1 | tail -1
```
Expected: prints Java version, no errors.

- [ ] **Step 3: Commit**

```bash
git add paperclip.conf
git commit -m "feat: add paperclip.conf with ZGC, CDS, and add-opens flags"
```
