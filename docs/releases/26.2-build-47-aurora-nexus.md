# SourbyCraft 26.2 Build 47 — Aurora Nexus

Status: IMPLEMENTATION IN PROGRESS

Java: 25  
Engine: Aurora Engine

## Release pillars
- Aurora Compatibility Bridge
- Aurora Instant Startup Cache
- Aurora World Fabric
- Aurora Execution Fabric and Resource Governor
- Network/storage observability
- Structured startup and plugin diagnostics

## Safety order
Correctness > reliability > data safety > stability > compatibility > tail latency > resource efficiency > startup performance > scalability > throughput.

## Public identity
Public branding is **SourbyCraft 26.2 Build 47 — Aurora Nexus**. Paper, Folia, Canvas, Moonrise and AdvancedSlimePaper are implementation/provenance inputs, not public build suffixes.

## Mandatory release gates
Build 47 MUST NOT be declared STABLE until compile, unit/integration, patch regeneration, plugin compatibility, region ownership, world load/unload/save, crash recovery, cache corruption, backend failure, startup, stress, soak and shutdown qualification pass.

## Core contracts
- no expensive CallerRuns fallback onto region owners;
- no unbounded executor queues;
- no blocking filesystem/database work on region threads;
- no worker mutation of live region-owned state;
- no startup cache containing live runtime objects;
- no compatibility color/status stronger than observed runtime evidence;
- no release-wide performance percentage without comparable certified evidence.

## Implementation status

Status is per pillar and reflects code on the `26.2` branch, not qualification. "Unit-tested"
means JUnit coverage of the new classes run on Java 25; none of the rows below has been through
the mandatory release gates above, and the full server build (which needs the private toolchain)
has not been run for this change.

| Pillar | State | What exists | What does not |
| --- | --- | --- | --- |

Publication controls (see `.github/workflows/build.yml`):

- Releases are published only from pushes to `release/26.2-canvas`, which is currently an
  ancestor of `26.2`; publishing Build 47 means fast-forwarding that branch.
- `release=pre` in `gradle.properties` publishes a GitHub prerelease. The auto-updater, whose
  default `apply_mode` is `auto`, skips prereleases unless `misc.auto_update.allow_prerelease`
  is set, so servers are not moved to Build 47 automatically.
- Set `release=true` only after every gate above is closed; that is the STABLE declaration.
- The release body includes this file (matched as `docs/releases/26.2-build-47-*.md`).
