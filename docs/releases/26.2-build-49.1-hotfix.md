# SourbyCraft 26.2 Build 49.1 — hotfix (Aurora Nexus)

Release source: `hotfix/26.2-r49.1`, based on `v26.2-r49`.
Publication requires the official build, boot and independent reproducibility jobs to pass.
Java: 25 · Minecraft: 26.2 · Engine: Aurora Engine. No STABLE claim.

## Changes

- The AbyssLink interoperability harness asserted absent and stale ping samples
  with `Optional.filter(predicate -> false)`, a condition that can never pass.
  `ping-absent` and `ping-stale` therefore failed even when the client correctly
  returned no sample, and `java-harness` exited non-zero as a consequence. The
  harness now expects `Optional.empty()` for those two checks; matched samples
  keep their predicate. Test-only change — no server runtime code, configuration
  key, protocol field or gameplay behavior changes.

The hotfix backports only this test fix. Build 49.1 contains no Build 50 work
(AWF multi-profile/Redis fabric, the SourbyMod loader, versioning 26.3) and no
other Build 49 changes.

## Operator behavior

None. No configuration key is added, renamed or re-read; the shipped jar's
runtime behavior is identical to 26.2-r49. Operators do not need to update for
this hotfix unless they run the AbyssLink interoperability harness.
