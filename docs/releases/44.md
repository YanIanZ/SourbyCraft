# SourbyCraft 26.2 — Build 44c, Pulse

This release establishes the first modernization increment from SPEC.md, PLAN.md,
and PRD.md while retaining the Paper → Canvas → SourbyCraft patch architecture.

## Changes

- Repair patch 0017 so `Entity.isInWall` compiles after source regeneration.
- Add `/ram` and `/perf` views: `tick`, `cpu`, `memory`, `gc`, `region`, `health`.
  Views consume the existing canonical metrics snapshot. Missing measurements
  remain unavailable; region coordinates and queues are not yet instrumented.
- Add `/perfbar` combining TPS/MSPT/RAM/CPU. HUD choices are per player, and
  `/tpsbar on|off`, `/rambar on|off`, `/perfbar on|off` are idempotent.
- Extend the read-only metrics API with default methods for CPU, committed heap,
  non-heap, Linux process RSS, uptime, platform threads, and GC totals. Existing
  implementations remain compatible and default to unavailable values.
- Record canonical telemetry in JFR; add an IntelliJ run configuration, profiling
  script, metadata, GC log, heap/thread diagnostics, and configuration hash check.
- Bound blocking administrative I/O to 64 admitted virtual-thread tasks with no
  queue. Saturation rejects promptly. Shutdown prevents lazy restart; cancellation
  interrupts the submitted I/O. Shutdown drains/cancels queued path futures.
- Stop utility services explicitly; publish GC samples immutably and stop the
  sampler. Retain metrics service availability through plugin disable.
- Publish an immutable utility-config snapshot at load/reload/save boundaries.
  Existing TOML files are not saved during default seeding. Explicit `/maxp`
  persistence and explicit config reload remain supported.
- Retire SmartSwap and automatic OS swap creation. Existing legacy keys are left
  intact and an enabled legacy setting produces a warning. The legacy launcher
  no longer chooses heap/GC flags or automatically forks for CDS. An explicit CDS
  fork preserves the operator's performance arguments.
- Auto-release watches `release/26.2-canvas`, shares a single validated build/tag
  identity, checks JAR metadata parity, and publishes only after tests, boot, and
  Docker gates. Numeric, dotted, hotfix, and historical `43c` tags reserve their
  major build number. The next release is `v26.2-r44`.

## Compatibility and operational changes

Java 25 remains required; preview mode is not required. Public build suffix `c`
is retained so manifest, banner, `/ver`, and updater stay compatible. Codename is
Pulse. Canvas/Paper/Spark copyright and source attribution remain intact.

Operators previously using SmartSwap must manage JVM memory and OS swap directly.
No server setting, entity limit, AI interval, view/simulation distance, compression,
autosave interval, or gameplay workload is automatically reduced by this update.

## Scope and validation

See [profiling instructions](../PROFILING.md) and [architecture audit](../MODERNIZATION-AUDIT.md).
The release's CI run is the authority for the published artifact. Local recordings
and test reports live under ignored `build/` directories, with their exact jar hashes.

This is not completion of the entire modernization roadmap. A dedicated SourbySpark
fork/viewer, per-region CPU attribution, actionbar HUD mode, advanced network/plugin
instrumentation, the 10/50/100-player workload matrix, multi-hour soak, and measured
gameplay optimizations remain future milestones. No performance percentage or
universal bug-free claim is made from the boot and idle smoke tests.
