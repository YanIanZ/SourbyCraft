## Operator behavior

`aurora.bridge.mode` remains `off` by default. With `mode = "safe"`, the owner's 2026-10-22 decision
("Tiru penuh LightingLuminol") makes `aurora.bridge.thread-checks = "relaxed"` the default, including existing
safe-mode servers without that key. `enforced` restores ownership refusals; `bridged` relaxes only bridged task
bodies. The key is RESTART_REQUIRED, read early; `-Daurora.bridge.thread-checks=` overrides it. Mode `off`
keeps checks enforced regardless of the configured value. New `aurora.toml` files contain the key and explanation;
existing operator files are preserved. `/ver`, `/perf plugins`, `/sourbycraft config`, plugin diagnostics and the boot log show the mode.

Relaxed/bridged checks permit foreign-thread access; data races, persisted world corruption, item duplication
and deadlocks remain possible. These modes are unsafe and unqualified. Functional tests and boots do not
establish plugin safety or release-wide performance. Player gameplay, portal cancellation/redirection in real
plugins, broader AWF concurrency and sustained soak remain owner acceptance gates.

Legacy `PlayerTeleportEvent`/`PlayerPortalEvent` support also runs in enforced mode. Its independent restart-only
escape hatch is `-Daurora.compat.async-teleport-events=false`.
