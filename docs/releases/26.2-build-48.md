## Scope

- **Startup output.** Boot→`Done` console and file logs without raw ANSI on non-terminals,
  without `dev.iyanz.*` / `io.canvasmc.*` logger names, with repeated lines collapsed and tidy
  stage output (Paper feature 0016, log4j plugins, `BootLog`; in progress 2026-10-21). Inherited
  log wording such as "Initialised EDF Folia scheduler" replaced with SourbyCraft wording.
- **Inherited guards → owned decisions.** Inventory of every Canvas/Folia hard guard (`if (true)`
  disables, `Unsupported` paths in region threading, disabled vanilla/Paper features) with one
  owned decision each (keep with rationale / replace / remove), pinned by a policy script. First
  replacement: SourbyCraft-owned region-safe command blocks behind a flag (MC feature 0055). The
  ENG-11 `execute if/unless … run` refusal (MC 0016) gets its decision here.
- **Bridge compatibility fixes** waiting for a server run: SuperiorSkyblock2 2026.3 adapter with
  the real jar, LightingLuminol global-scheduler acceptance, same-instance re-enable (Paper 0012),
  `FairLane` on `BRIDGE_IO` (owner sets weights).
- **UX, commands, observability polish.** `/tps`, `/mspt`, `/perf`, HUD bars consistent with Sourby
  metrics; Spark viewer config and Aurora metadata; region context in profiles; AWF dirty-age row;
  ASP→AWF review leftovers (B76).
- **Independence refinements.** M-1 identity (crash reports, profiler identity), M-2 isolation
  slices (0005/0006/0013/0021, Canvas Spark bridge), owned-source rule with regression tests for
  0009–0012, release-branch name decision.
- **Tooling.** Private toolchain dependency update and re-pin; `agent_worktree` and
  `agent_testserver` fixes.
- **Docs.** Stale checkboxes ticked or reworded (e.g. `MobPathSnapshot`, implemented as MC 0039).

Out of scope: soaks, persistence/crash qualification, security activation, reproducibility
(Build 49); baselines, profiles, optimizations, async pathfinding default (Build 50).
