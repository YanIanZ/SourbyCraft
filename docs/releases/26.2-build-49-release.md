# SourbyCraft 26.2 Build 49 — Aurora Nexus (normal release)

Release source: `26.2` at the merge of PR #54 (`2b499e34`).
Java: 25 · Minecraft: 26.2 · Engine: Aurora Engine. **No STABLE claim**: the gates in
[26.2-build-49.md](26.2-build-49.md) remain open.

This is the first release that contains the Build 49 configuration layout and the YAML config files.

## Changes since the Build 48 line

- **YAML configuration with a one-time conversion.** `sourbycraft_config/aurora.yml` and
  `sourbycraft_config/sourbycraft_global_config.yml` replace the TOML files. On the first boot an
  existing `*.toml` is parsed, written as `*.yml` with every value **and comment**, and renamed
  `*.toml.migrated`; a `*.yml` always wins, a read-only directory keeps reading the TOML, and an
  unparseable file is left untouched and named with file + near-line. Build 49 key layout
  (`console`, `players`, `messages`, `plugins.*`, `updater`; `aurora.*` services) as described in
  [AURORA-CONFIG.md](../AURORA-CONFIG.md).
- **AbyssLink (optional, disabled by default).** A bounded, verified-mTLS client for Leviathan's
  separate control listener (heartbeat, proxy ping samples, health reports, advisory threat
  signals) and a Folia-safe native `/ping`. Gameplay forwarding and admission are unchanged; a
  configuration or TLS failure logs one WARN and leaves the server fully available. See
  [docs/abysslink](../abysslink/README.md).
- **Shutdown fixes from 48.4.** A sync chunk load requested from the region shutdown thread is
  refused with an owned message instead of throwing `Polling tasks from non-owned region` (or
  hanging); a stopped `BRIDGE_IO` lane is reported as stopping, rate-limited, without a stack
  trace; config parse failures name the file and near-line.
- The earlier 26.2 work merged since `v26.2-r48` (relaxed thread checks, teleport/portal seams,
  bridging context routing, PaperLib 26.x compatibility, off-thread chunk waits) is included; see
  `git log v26.2-r48..v26.2-r49` for the full list.

## Operator behavior

- Back up `sourbycraft_config/` before the first boot. The conversion is one-way: to downgrade,
  delete or rename the `*.yml` file and restore `*.toml.migrated` to `*.toml`.
- An unparseable old TOML is not converted and not renamed; the server logs the file and near-line
  and uses documented defaults for values it cannot read.
- AbyssLink stays off until `aurora.abysslink.enabled: true` and a backend client certificate/key are
  configured; `tls: false` is rejected.
- Thread-check defaults and the bridge mode are unchanged from 48.4.
